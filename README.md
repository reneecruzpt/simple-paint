# Simple Paint — Mini Estúdio de Desenho em Python (Turtle)

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![GUI](https://img.shields.io/badge/GUI-Turtle%20Graphics-green)](https://docs.python.org/3/library/turtle.html)
[![Dependencies](https://img.shields.io/badge/Dependencies-Zero%20(Standard%20Library)-success)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Aplicação desktop interativa de desenho e pintura desenvolvida em **Python** utilizando a biblioteca padrão **Turtle Graphics**. O projeto inclui uma paleta gráfica lateral, atalhos de teclado completos, controlo de espessura do pincel, preenchimento de polígonos e alternância entre modo diurno e noturno.

---

## 🎨 Funcionalidades

- **Desenho Livre com o Rato:** Arraste para traçar livremente na tela. Clique num ponto para mover o pincel sem rabiscar.
- **Paleta de Cores Rápida:** Troca instantânea de cores através do teclado.
- **5 Níveis de Espessura:** Do traço fino (5px) ao preenchimento largo (35px).
- **Preenchimento de Formas:** Inicie e finalize o preenchimento de figuras geométricas complexas.
- **Modo Dia / Noite:** Alterne a cor da tela de desenho entre branco e preto.

---

## ⌨️ Tabela de Atalhos & Comandos

| Comando | Tecla / Ação | Descrição |
|---|:---:|---|
| **Desenhar** | `Arrastar Rato` | Traça linhas livres na tela |
| **Mover** | `Clique Rato` | Teleporta o pincel sem riscar |
| **Vermelho** | <kbd>R</kbd> | Pincel na cor vermelha |
| **Verde** | <kbd>G</kbd> | Pincel na cor verde |
| **Azul** | <kbd>B</kbd> | Pincel na cor azul |
| **Laranja** | <kbd>O</kbd> | Pincel na cor laranja |
| **Amarelo** | <kbd>Y</kbd> | Pincel na cor amarela |
| **Azul Claro** | <kbd>L</kbd> | Pincel na cor azul clara |
| **Violeta** | <kbd>V</kbd> | Pincel na cor violeta |
| **Espessuras** | <kbd>1</kbd> a <kbd>5</kbd> | Ajusta o tamanho da ponta do pincel (5px a 35px) |
| **Preencher** | <kbd>F</kbd> / <kbd>E</kbd> | <kbd>F</kbd> inicia o preenchimento; <kbd>E</kbd> finaliza |
| **Tema Fundo** | <kbd>D</kbd> / <kbd>N</kbd> | <kbd>D</kbd> modo diurno (branco); <kbd>N</kbd> modo noturno (preto) |
| **Mover Pincel** | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Desloca a tartaruga pelas setas do teclado |

## 🚀 Como Executar

O projeto utiliza exclusivamente a biblioteca padrão do Python, **não requerendo nenhuma instalação via pip**:

1. Clone o repositório:
   ```bash
   git clone https://github.com/reneecruzpt/simple-paint.git
   cd simple-paint
   ```

2. Execute o programa:
   ```bash
   python main.py
   ```
